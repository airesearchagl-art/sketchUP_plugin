# Smart Framing Tools v1.0.0

> **"More Vibe, Less Clicks."**
> 建築設計の実務を加速させる、SketchUp 専用のフレーム編集ツールセット。

---

## 概要

**Smart Framing Tools** は、柱・梁・間柱といった構造部材の端部調整を「直感的かつ数学的に正確」に行うための SketchUp 拡張機能です。

従来は「面を選択 → PushPull → はみ出しを手動でカット」と複数手順が必要だった作業を、**2 クリック**で完結させます。
Vibe Coding（AI との共創）によって開発され、建築設計者が最もストレスを感じる「微細な端部調整」を自動化します。

| 項目 | 要件 |
|---|---|

| OS | Windows / macOS |

---

## 主な機能（v1.0.0）

| ツール | 操作 | 説明 |
|---|---|---|
| **Trim（トリム）** | 境界ソリッド → 切り落とす端部をクリック | 基準部材を超えてはみ出した端部をブーリアン演算で除去。同一境界に連続使用可能。 |
| **Split（分割）** | 境界ソリッド → 分割対象をクリック | ハーフスペースカッター法により、1 本の部材を境界面で 2 つの独立したソリッドに分割。 |
| **Align（位置合わせ）** | 基準面 → 揃えたい面をクリック | 基準面の平面方程式から移動量を算出し、ブーリアンを使わない純粋な平行移動でツラ揃え。 |
| **Extend（延長）** | 境界面 → 伸ばす部材の端面をクリック | 境界面を超えるまでオーバーシュート延伸し、境界でトリム。同一境界に連続使用可能。 |

## インストール方法

1. Releases ページから `su_smart_framing_tools_v1.0.0.rbz` をダウンロード
2. SketchUp を起動し、**拡張機能** メニュー → **拡張機能マネージャー** を開く
3. **拡張機能をインストール** をクリックし、ダウンロードしたファイルを選択
4. SketchUp を再起動すると、ツールバーに 4 つのアイコンが表示されます

## 技術的な特長

### 小口（端面）優先選択ロジック
部材の定義バウンディングボックス（`definition.bounds`）から長手軸を判定し、側面ではなく**端部（小口面）を優先**してピックします。回転・スケールがかかった部材でも正しく機能します。

### 座標系完全同期
カッター（ブーリアン演算用の一時ソリッド）を、ターゲット部材と**必ず同じ `Entities` コレクション内**に生成します。入れ子（ネスト）構造や任意の変換が施された部材でも `subtract` が確実に成功します。

### スケール補正済み PushPull
ワールド座標で算出した延伸距離を、部材のローカル変換スケールで除算してから `pushpull` に渡します。スケールが適用されたコンポーネントでも正確な距離で延伸できます。

### アンドゥ対応
すべての操作は SketchUp のトランザクション（`start_operation` / `commit_operation`）内で実行されます。失敗時は自動でロールバックされ、Ctrl+Z（Cmd+Z）でも完全に取り消せます。
